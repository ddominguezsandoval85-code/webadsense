# The Curious Backpack

Honest, budget-friendly travel guides by Daniel, published at https://www.thecuriousbackpack.com.

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No build step and no dependencies.

## Google AdSense

1. Add the AdSense `<script>` to the `<head>` of every page (look for the `GOOGLE ADSENSE` comment).
2. Replace `pub-XXXXXXXXXXXXXXXX` in `ads.txt` with your publisher ID.
3. Every `<div class="ad-slot">` stays hidden until you paste an AdSense `<ins class="adsbygoogle">` tag inside it.
